# 白同学短剧助手 UI 主题与布局方案

## 1. 方案范围

本方案只处理界面视觉和排版，包括：

- 顶部导航布局
- 页面信息层级
- 三种主题切换
- 护眼和低对比显示模式
- 创作配置页面的视觉分组
- 生成页面的 Skill 选择控件展示
- 各页面的间距、颜色、卡片、表格和滚动区域

本方案不修改：

- 业务流程
- 业务代码
- 现有功能
- API 接口
- 数据库结构
- 视频生成提交逻辑
- 提示词生成规则
- Skill 内容和 Skill 执行规则
- 任务状态轮询和回传逻辑

Editorial Copper 主题从本次方案中移除。

## 2. 保留的三种主题

### 2.1 Obsidian Cyan

定位：专业生产控制台。

- 背景：黑曜石深灰
- 面板：深灰蓝
- 主色：冷银
- 强调色：荧光青
- 适用页面：分镜工作台、生成页面、任务状态、画布模式
- 视觉特点：信息密度高、状态清晰、适合长时间操作

### 2.2 Warm Studio

定位：电影工作室与素材档案。

- 背景：暖灰
- 面板：米白和浅灰
- 主色：焦糖
- 强调色：砖红和胶片黄
- 适用页面：项目列表、剧集详情、素材库、自由创作
- 视觉特点：柔和、稳定、有制作感

### 2.3 Neo Jade

定位：现代东方短剧制作平台。

- 背景：深墨绿或温白
- 面板：温白、浅玉色
- 主色：玉绿色
- 强调色：朱砂红
- 适用页面：品牌主页、项目管理、创作配置、画布模式
- 视觉特点：克制、清晰、具有品牌识别度

## 3. 全局主题切换

主题切换入口放在顶部导航右侧的用户工具区，保持所有页面位置一致。

建议提供：

- Obsidian Cyan
- Warm Studio
- Neo Jade

主题切换只改变：

- 背景色
- 面板色
- 边框色
- 强调色
- 文字颜色
- 阴影和分隔线
- 图片缩略图边框
- 状态标签颜色

主题切换不改变：

- 导航顺序
- 页面入口
- 表单字段
- 按钮功能
- 数据内容
- 业务流程

## 4. 护眼显示模式

护眼模式作为独立的视觉显示选项，可以与三种主题组合使用。

### 4.1 标准模式

- 使用主题的完整对比度
- 适合白天和快速操作
- 保留当前主题的强调色

### 4.2 护眼模式

- 降低纯白和纯黑的使用比例
- 降低高饱和度青色、红色和黄色
- 将背景调整为偏暖灰或深灰绿
- 减少面板边缘的强发光效果
- 保持文字和控件的可读性

### 4.3 低对比模式

- 降低面板之间的明暗跳变
- 减少阴影和高亮边框
- 保留选中、警告、生成中等必要状态颜色
- 适合长时间浏览项目和素材

护眼模式只改变视觉显示，不改变任何交互和功能。

## 5. 顶部导航结构

所有页面采用统一的顶部导航，参考 Obsidian Cyan 套图。

左侧：

- 平台名称
- 当前项目或工作区标识

中间主导航：

1. 项目
2. 剧集创作
3. 素材库
4. 自由创作
5. 创作配置
6. 画布模式

右侧工具区：

- 搜索
- 通知或任务状态入口
- 主题切换
- 护眼模式切换
- 用户菜单

顶部导航在页面切换时保持高度、位置和视觉样式一致。

## 6. 创作配置页面

“创作配置”作为统一的配置入口，只改变页面组织方式，不改变原有配置内容和规则。

左侧二级导航：

- 模式配置
- 视频提示词规则
- Skill 设置
- 其他已有配置

右侧内容区：

- 保留原有配置字段
- 按卡片或分组展示
- 保留原有保存、启用、禁用和编辑入口
- 显示当前启用状态
- 显示规则包或 Skill 的名称和版本

页面不新增自动改写规则，也不在 UI 层改变提示词生成方式。

## 7. 生成页面中的 Skill 选择

生成页面在提示词输入区域附近增加一个视觉明确的“选择 Skill”控件。

控件建议包含：

- 当前 Skill 名称
- Skill 类型或用途
- 版本号
- 启用状态
- 下拉选择入口
- 查看详情入口

生成页面只负责展示和选择已有 Skill。Skill 的编辑、安装、规则内容和执行逻辑仍归属于“创作配置”页面及现有系统。

## 8. 分镜工作台布局

分镜页面保持按镜头工作的结构：

- 左侧：镜头队列，独立滚动
- 中间：当前镜头预览和镜头信息
- 右侧：提示词、参考图、生成检查和现有操作按钮

主题切换只改变颜色和排版，不改变镜头顺序、镜头字段、时长字段或生成提交方式。

## 9. 其它页面套用规则

### 项目列表

- 顶部导航固定
- 项目卡片采用统一缩略图比例
- 状态标签保持一致
- 搜索和筛选位置固定

### 剧集详情

- 剧集概览放在上方
- 剧集列表和进度状态放在主体区域
- 进入分镜工作台的按钮保持原有位置逻辑

### 素材库

- 保留视频、图片、音频等原有分类
- 使用统一缩略图网格
- 上传、筛选和搜索保持现有功能

### 自由创作

- 输入区域、风格选择、时长和画幅控件保持原有功能
- 采用与生成页面一致的控件样式

### 画布模式

- 保留现有节点、连线和画布操作
- 仅优化工具栏、缩放控件、节点卡片和背景网格

## 10. 主题设计变量

前端实现时建议将颜色和间距集中为 UI 设计变量：

- `--ui-bg`
- `--ui-surface`
- `--ui-surface-raised`
- `--ui-border`
- `--ui-text-primary`
- `--ui-text-secondary`
- `--ui-accent`
- `--ui-accent-muted`
- `--ui-success`
- `--ui-warning`
- `--ui-danger`
- `--ui-radius`
- `--ui-shadow`

主题和护眼模式只替换这些视觉变量，不修改组件业务逻辑。

## 11. 验收标准

- 三种主题可以在顶部导航中切换
- 三种主题使用相同的导航结构和页面结构
- 每种主题都支持标准、护眼、低对比显示模式
- 顶部导航在项目、剧集、分镜、配置、素材库、自由创作、画布页面保持一致
- 创作配置页面能同时承载模式配置、视频提示词规则和 Skill 设置的视觉分组
- 生成页面能看到 Skill 选择控件
- 现有按钮、字段、页面入口和业务行为保持不变
- 不新增或修改提示词规则、Skill 规则、视频生成流程和任务提交逻辑
- 不修改数据库、API、后端服务和业务代码

## 12. 推荐实施顺序

1. 先统一顶部导航和全局布局容器
2. 建立三套主题变量
3. 增加标准、护眼、低对比三种显示模式
4. 调整创作配置页面的视觉分组
5. 在生成页面补充 Skill 选择控件的 UI 展示
6. 依次适配项目、剧集、分镜、素材库、自由创作和画布模式
7. 做不同主题下的页面回归检查

本方案完成后，平台只是拥有新的 UI 主题和布局呈现，原有流程、业务代码、功能和规则保持不变。
