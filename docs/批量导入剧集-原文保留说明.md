# 批量导入剧集：格式适配与原文保留

入口：项目列表 → 打开项目 → 剧集管理 → 批量导入剧集。

## 使用步骤

1. 选择原始 TXT 或 MD 文件。无需先修改标题、字幕或报告特写标记。
2. 默认使用“自动识别集标题”。支持 `第八集`、`## 第八集 亲子鉴定`、`【第八集】` 等格式。
3. 选择目标集号：默认顺序追加；需要导入为第八集时，选择“使用原文集号”。已有集号或文件内重复集号会阻止导入。
4. 点击“检查格式并预览”，核对集标题、场次、目标集号及每集全文。
5. 勾选核对确认后，点击“确认原文导入”。只有保存请求成功后才提示导入成功；失败时保留预览以便重试。

原稿 `第八集剧本.txt` 的检查结果：第八集《亲子鉴定》，1 集、4 场、2421 个字符（包含标题和换行），UTF-8 共 5553 字节。正文逐字符一致，UTF-8 字节一致。

## 内容保留约定

- 不调用 AI，不润色、不压缩、不调整对白、动作或叙事顺序。
- 每集正文直接截取原文件对应范围，保留原始标题、Markdown 符号、空格、空行及 CRLF/LF 换行。
- 所有分集正文按顺序拼接后，必须与解码后的原文严格相等；预览和提交前均检查。
- 独立的集标题字段会去掉 Markdown 外壳，便于列表展示。正文里的标题仍保持原样。
- `### 8-1` 是场次；`【字幕】`、`【报告特写】` 是正文；`第八集完` 不会成为新集。
- 标题前的前言保留在首集，并提示核对。无可识别标题时按单集预览，也可主动选择整份文件作为一集。
- 场次统计仅供检查，按明确场次标记统计；未识别到场次不会删除正文。
- 自定义章节正则在高级模式中保留，按行匹配；每集章节数也只在高级模式使用。按原文连续范围合并，不重写或重排内容。

## 编码与边界

自动模式读取 UTF-8，或通过 BOM 识别 UTF-16。GBK 文件可手动选择 GB18030；读取失败或发现损坏字符时阻止继续，需核对编码。字符数以程序字符串长度统计（UTF-16 代码单元），包含空白；它与文件字节数不同。

本次更新针对“批量导入剧集”。创作页旧的“导入小说 / AI 转换”入口、故事生成规则和后续分镜/视频生成逻辑未修改。需要保留原稿时请使用此批量入口。原文保留保证针对本次导入，后续手动编辑、保存或 AI 生成属于独立操作。
